GWO-XCGIDS: An Explainable Hybrid CNN–GRU Intrusion Detection Framework for Secure IoMT Networks

## 👥 Author

S. Balaji

📌 Overview

This repository contains the datasets, source code, and embedded deployment files developed for the research framework **GWO-XCGIDS**, an explainable hybrid deep learning-based Intrusion Detection System (IDS) designed to improve cybersecurity in Internet of Medical Things (IoMT) networks.

The proposed framework integrates three principal components:

- **Grey Wolf Optimizer (GWO):** Optimizes feature selection to identify informative network traffic features while reducing feature dimensionality.
- **Hybrid CNN–GRU:** Combines convolutional feature extraction with gated recurrent learning to capture spatial and temporal characteristics of IoMT network traffic.
- **SHAP Explainability:** Provides feature-level explanations to improve the interpretability and transparency of intrusion detection decisions.

The framework is evaluated using three IoMT-related datasets:

1. WUSTL-EHMS-2020
2. MedSec-25
3. IoMT-IND2026

The primary objective is to develop an accurate, computationally efficient, and interpretable intrusion detection framework capable of identifying malicious activities in resource-constrained and security-sensitive IoMT environments.

## ✨ Key Features

### 🐺 GWO-Based Feature Optimization

Employs the Grey Wolf Optimizer to identify an informative subset of network traffic features. The optimization process aims to improve classification performance while reducing feature dimensionality and redundancy.

### 🧠 Hybrid CNN–GRU Architecture

Integrates CNN and GRU components to learn complementary representations from network traffic data.

- **CNN:** Extracts discriminative feature representations.
- **GRU:** Learns temporal dependencies in sequential traffic patterns.
- **Hybrid architecture:** Combines spatial and temporal feature learning for intrusion detection.

### 🔍 Explainable AI Using SHAP

Integrates SHAP-based explainability to interpret the predictions generated by the proposed detection model. Feature contributions are analyzed to identify the most influential attributes associated with intrusion detection decisions.

### 🏥 Multi-Dataset IoMT Evaluation

Evaluates the proposed framework across three datasets to examine its effectiveness under different IoMT network traffic characteristics and attack scenarios.

### ⚙️ ESP32-Based Embedded Deployment

Includes an embedded evaluation using the ESP32-WROOM-32E platform to investigate the practical feasibility of deploying the proposed intrusion detection framework in resource-constrained IoMT environments.

## 📊 Datasets

The proposed framework is evaluated using three datasets. All three CSV dataset files have been uploaded to the repository under the `datasets/` directory.

### 1. WUSTL-EHMS-2020

The WUSTL-EHMS-2020 dataset is used to evaluate intrusion detection performance in an electronic healthcare monitoring environment.

- Original features: 44
- Features selected by GWO: 16

### 2. MedSec-25

The MedSec-25 dataset is used to assess the detection capability of the proposed framework under medical and IoMT-related cybersecurity scenarios.

- Original features: 77
- Features selected by GWO: 27

### 3. IoMT-IND2026

The IoMT-IND2026 dataset is used to further evaluate the framework under IoMT network intrusion detection scenarios.

- Original features: 12
- Features selected by GWO: 5

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/balajisaba/GWO-XCGIDS-IoMT-Intrusion-Detection.git
```

Navigate to the repository:

```bash
cd GWO-XCGIDS-IoMT-Intrusion-Detection
```

### 2. Create a Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```
